STRING MANIPULATION

Indexing: Relate to the number or position of each character.
Slicing: Grabbing multiple characters [start:stop:step]

text = "Python Programming"

print(text[0]) # first character
print(text[-1]) # last character
print(text[0:6]) # slice 0 to 5, will print first 5 characters
print(text[:6]) # will print from start to 5
print(text[7:]) # will print 7 to end

STRING MANIPULATION / METHODS

name = "bob the builder"

print(len(name)) # count the character length
print(name.strip()) # remove the whitespace
print(name.upper()) # uppercase the string
print(name.lower()) # lowercase the string
print(name.title()) # Titlecase the string, similar to PROPER in excel
print(name.replace("old", "new")) # Replace the specific part of a string
print(name.split()) # Split the data based on space, the outcome will be ["bob", "the", "builder"]
