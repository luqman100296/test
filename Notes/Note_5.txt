LOOPS

TYPES

For Loop: known iteration (you know how many times to repeat)
While Loop: unknown iteration (repeats until a condition changes)

Rule of thumb: if you can count it, use for. If you're waiting for a condition, use while.

FOR LOOP SYNTAX

for i in range(5):
    print(i)
# prints 0, 1, 2, 3, 4

range(5) = 0 to 4
range(1, 6) = 1 to 5
range(0, 10, 2) = 0, 2, 4, 6, 8 (step of 2)

Looping over a list:

python
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

WHILE LOOP SYNTAX

count = 0
while count < 5:
    print(count)
    count += 1

Careful: forgetting to update the condition variable causes an infinite loop.

LOOP CONTROL STATEMENTS

break: exits the loop immediately
continue: skips to the next iteration
pass: does nothing, just a placeholder

for i in range(10):
    if i == 5:
        break       # stops loop entirely at 5
    if i % 2 == 0:
        continue    # skips even numbers
    print(i)

num = int(input("Enter a number: "))
for i in range(1, 11):
    print(f"{num} x {i} = {num * i}")

Explanation: 
- first line is an input syntax with an integer delimitation. 
- Second line is the for loop syntax. It will create a loop for i from 1 to 10.
- Third line is f-function, embedded with mathematical operations. So it will take the number input from the user and times it with i which is number that is being looped (from 1 to 10).

2. Find all primes up to 20

limit = 20
for num in range(2, limit + 1):
    is_prime = True
    for i in range(2, num):
        if num % i == 0:
            is_prime = False
            break
    if is_prime:
        print(num)

Explanation:
- The first line is the limit set using variable and data type.
- The second is the loop syntax, which it will loop from 2 to 20 (because if 2, 20 - it will come short to only 19).
- The third line is a boolean operator to and part of the conditional statement. It sets the first condition for the data.
- The forth line is basically in reference to the second line, it is another loop that will be divided with num - the data would be 2 to num.
- The fifth line is also another conditional statement, the math operation that goes with it is Modulus, where it will return 0 if there's no remainder after division.
- The sixth line is indented under the fifth line, so for any number between 2 to 20 that can be divided without any remainer with the for loop under the forth line, is not a prime number. And being denoted as False by the boolean operator.
- The seventh line is loop control statement, break will stop the loop.
